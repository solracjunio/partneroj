# Registro de decisões (ADRs)

Cada arquivo registra uma decisão técnica: o contexto, as opções consideradas, a escolha e as consequências.

- Nome do arquivo: `NNNN-titulo-curto.md` (por exemplo, `0001-dinheiro-em-centavos.md`).
- Um ADR aceito não é editado. Se a decisão mudar, um ADR novo o substitui e aponta para ele.

## Modelo

```markdown
# NNNN. Título

- Status: proposto | aceito | substituído por NNNN
- Data: AAAA-MM-DD

## Contexto
## Opções consideradas
## Decisão
## Consequências
```
